# FoodHub 🍔

FoodHub is a simple food ordering website I made using HTML, CSS, and JavaScript. It lets users browse different food items, add them to a cart, and check their total before checkout.

I built this project to practise frontend development and learn how the main features of an online food ordering website work.

## Features

- Browse food items, including pizza, burgers, and coffee
- Add items to the cart and change quantities
- Remove items from the cart
- View the total price before checkout
- Switch between light and dark mode
- Enter customer details during checkout
- Try the eSewa sandbox payment flow
- View a basic dashboard with menu and cart information
- Responsive layout for different screen sizes

## Built With

- HTML
- CSS
- JavaScript
- CryptoJS
- eSewa ePay sandbox

## Getting Started

You don't need to install anything to run this project.

1. Clone the repository:

   ```bash
   git clone https://github.com/bishalkshah70-art/FoodHub.git
   ```

2. Open the project folder:

   ```bash
   cd FoodHub
   ```

3. Open `index.html` in your browser.

That's it. You can explore the menu and try out the cart and checkout features.

## Payments

The project includes an eSewa sandbox payment flow for testing. It is not a production payment system, and successful payment verification is not handled by a backend.

A real payment system would need server-side signature generation, payment verification, and secure handling of merchant credentials.

## Current Limitations

FoodHub is currently a frontend project. Cart data and interactions run in the browser, and there is no backend or database connected to it.
